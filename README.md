🚚 Transportation Management System (TMS)

Backend Transportation Management System built using Node.js, Express.js, PostgreSQL, MongoDB, Docker, and GitHub Actions.



✨ Features



👨‍✈️ Drivers Management

➕ Create Driver

📋 View Drivers

✏️ Update Driver

🗑️ Delete Driver



🚛 Vehicle Management

➕ Create Vehicle

📋 View Vehicles

✏️ Update Vehicle

🗑️ Delete Vehicle



🛣️ Trip Management

➕ Create Trips

👨‍✈️ Assign Drivers

🚛 Assign Vehicles

⏱️ Track Start Time

🏁 Track End Time



🛠️ Technology Stack

🟢 Node.js

⚡ Express.js

🐘 PostgreSQL

🍃 MongoDB

🐳 Docker

🔄 GitHub Actions

🌿 Git
